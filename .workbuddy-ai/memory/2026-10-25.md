# 2026-10-25

## 个人网站（3D 人物 + 环绕导航）从零搭建

**技术栈**：Vite 5 + three.js 0.169 + GSAP 3.15（ScrollTrigger）+ Lenis 1.3
**目录**：`src/webgl/`（HeroScene / OrbitNav / HeroWords / text）、`src/ui`（未用，逻辑都在 main.js）、`src/content.js`（全部文案数据）

### 3D 模型处理链路（重要）
原始 `character-1025-full.glb` 19MB、261k 顶点、45 万面、单网格、无骨骼动画，贴图是黑白墨笔触。
- **杂质**：网格里混入 AI 生成的漂浮 3D 文字（"hmm" 等），是 z 方向厚度 <0.04 的薄片。
  → `tools/strip-artifacts.mjs` 按「连通分量 + z 极薄 + 位置在身体外」摘除（128 个分量 / 14631 面）
- **压缩**：`npx gltf-transform optimize --compress meshopt --texture-compress webp`
  → **25MB → 2.88MB**，肉眼无差。three 侧需 `loader.setMeshoptDecoder(MeshoptDecoder)`。
- 源文件留在 `assets/`（不进 public），线上只放 `public/character.min.glb`。

### 环绕导航 + 遮挡的实现要点
导航不是 DOM，是 **canvas 贴图的 3D 平面**：只有进 WebGL 才有真深度遮挡。
- 每帧 `mesh.quaternion.copy(camera.quaternion)` 做 billboard，所以转到背面也能读
- `transparent:true + depthTest:true + depthWrite:false` → 人物（不透明）挡住身后的字
- hover 反色用「同一位置叠一层反色贴图 + 透明度交叉淡入」，不要换材质（会闪）

### 踩过的坑（会再遇到）
1. **`-webkit-text-stroke: currentColor` 在 Chrome 解析成黑色** → 深色区块的描边标题全隐形。改成 CSS 变量 `--stroke`。
2. **CSS `transition` 与 GSAP 抢同一属性**：这个环境下 transition 走得极慢（2.5s 只走 63%），必须只留 GSAP 驱动。
3. **`gsap.fromTo` + scrollTrigger 的 `immediateRender`**：每次 refresh 会把元素重置回起始态 → 设 `immediateRender:false`。
4. **CSS `translateY(112%)` 会被 GSAP 解析成 `y:233px`**，之后动 `yPercent` 完全无效。初始态改用 `gsap.set({yPercent:112})`。
5. **`ScrollTrigger.create({onEnter})` 在直接跳转 + refresh 时不回调** → 一律用 `scrub` 绑进度，或 `gsap.from/fromTo` 绑 trigger。
6. 竖屏时按 viewportH 缩放 3D 文字会爆炸 → 用 `unit = min(wH, wW*1.15)` 归一化。

### 工具

### 取景（用户要求：只拍到裙子，裙摆压在页面底边）
`HeroScene.frame = { top: 1.11, bottom: -0.545 }`，`resize()` 里按 fov 反推相机距离和高度。
- 模型归一化后 y ∈ [-1,1]；白裙下沿约 -0.52，脚在 -0.9 以下
- 想再收/放，只改这两个数即可
- 导航标签加了白色描边（halo，`makeNavTexture` 里 strokeText 两遍再 fillText），否则压在黑衣服上会糊
