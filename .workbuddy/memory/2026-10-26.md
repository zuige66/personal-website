## 外链转场幕布：看不清 / 不新窗口 / 返回后残留

- **根因不是配色，是面板根本没上来**：`.veil__panel` 的 CSS 写了 `transform: translateY(102%)`，
  JS 又叠了 `gsap.set(panel, { yPercent: 102 })`，GSAP 解析 CSS 得到 918px 再叠加百分比 → 实际 1836px，
  黑幕永远停在视口下方。屏上只剩白字飘在浅色页面上，所以「看不清」。`label` 的
  `translate(-50%,-50%)` 与 `xPercent/yPercent` 同理会双重偏移（居中也偏）。
  修法：CSS 一律不写 `transform`，位置全交给 GSAP，`layout()` 在初始化与每次 reset 都跑一遍。
  判定方法看 `getComputedStyle(panel).transform` 的 `m42`：待命 918、盖满 0。
- **反色**：`mix-blend-mode: difference` + `color:#fff`，黑底出白、浅底出黑，不用维护两套颜色。
  关键约束：标签必须放在 `.veil` **外面**——`.veil` 有 `z-index:190` 自成层叠上下文，
  放里面只能和黑色面板混色，永远是白的。所以 `#veilLabel` / `#veilMeta` 改成幕布的兄弟节点，
  自身 `z-index:191`。
- **新窗口**：列表 `<a>` 补 `target="_blank" rel="noopener noreferrer"`；JS 只拦左键无修饰键的点击，
  播完转场再 `window.open(href,'_blank')`，被拦截时退回 `location.href`。
  开窗口的时机放在标签亮到位（约 0.68s），仍在用户激活 5s 窗口内。
- **返回残留**：`busy` 是闭包变量且无人复位（回来后点链接没反应）；`veil.is-on` 会被 bfcache 原样还回来；
  `#projFloat/#blogFloat` 的 `is-on` 只靠 `pointerleave`，跳转时指针没离开就跳走了。
  统一收进 `reset()`，挂在 `visibilitychange`(visible) / `pageshow`(persisted) / `popstate` 三处。
  注意新窗口一开本页就进后台，`rAF` 停摆、动画冻在半路，这一层是关键兜底。
- 工具：`tools/veil-frames.mjs` 逐帧采样（会把 `window.open` 打桩，否则抓到的帧全错位）、
  `tools/veil-check.mjs` 验证真实开窗与返回态。
- 文档：新建 `docs/link-transition.md`。

## 转场收紧：只留「黑屏 + 白字」

- 用户看到实验图（强制把标签贴在浅色页面上验 `difference`）觉得乱，诉求是「跳转时黑屏白字就好」。
  那张图不是真实流程会出现的画面，但暴露了一个真问题：`difference` 让文字压在任何底色上都可见，
  于是提前淡入也不会「消失」，只是变成一个半压在页面上的中间态。
- 改严格串行：panel `yPercent` 到 0 之后才动 label 透明度（`'+=0.05'`，原来是 `'-=0.16'` 重叠）。
  验收口径：任何一帧 `label.opacity > 0` 时 `panel.m42` 必须已经是 0。
- 转场期间隐藏自定义光标：hover 态是 62px 实心白圆，被 `difference` 反成白色压在墨幕大字上像块破洞。
  加 `body.is-veil` 类，跟 `is-on` 同进同出，`reset()` 里一并摘掉。
- 总时长压到约 1.8s。

## 部署上线（Cloudflare Workers Git 集成）

- 部署方式：**没有本地 wrangler 凭据，全靠 CF 侧 Git 集成**。`wrangler.jsonc` 里
  `assets.directory = ./dist`，`dist/` 在 `.gitignore` 里 → CF 拉仓库后自己跑 `npm run build` 再发静态资产。
  所以只要 `git push origin master` 就自动上线，约 1 分钟出结果，不需要手动拖 dist。

  与本地 `dist/` 是否同一个 hash，再 `grep is-veil` 确认新逻辑在里面。

## 滚动动效（对标 lusion.co）

- 对照 lusion.co 后确认对方是虚拟滚动（body 高度=视口、scrollY 恒 0、3 canvas + 9 fixed），
  curl exit 35 + Playwright 卡在加载条，改用 DOM 度量取证，没有硬啃。
- 补的四处动效：滚动速度 → `skewY`（`quickSetter`，clamp ±2.2°，衰减 0.8s power3）、
  照片视差（`yPercent -5→5` + `scale 1.14` + scrub）、标题按 `<br>` 拆行做 overflow 遮罩、
  顶部 2px 全局进度条（`ScrollTrigger end:max` 喂 `scaleX`）。
- `skew` 不要作用在 `#main`：近两万像素高，绕中心斜 2° 边缘甩出 400+ px 会露白边，
  改成枚举中等高度容器（`.wrap` / `.photo-grid` 等）。
- 3D 淡影贯穿：`.statement` 背景必须 `transparent` 才看得见 canvas；
  `ghostAlpha()` 竖屏 0.08 / 横屏 0.12（竖屏人物占满画面，同样透明度会压住正文）；
  淡影前 65% 只轻微减弱、后 35% 收干净，两段在 p=0.65 取值都 0.805，接得上。
- 验收数据：整页扫到底 `#progressBar` matrix(1,0,0,1,0,0)、无横向滚动条、
  `#gl` opacity 归 0 且 `scene.active === false`、控制台零报错。
